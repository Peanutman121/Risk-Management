# Portfolio Risk Management System

A comprehensive risk management system for a rates trading desk with 5 traders, consisting of:
1. **Excel Template** - Per-trader position tracking workbook
2. **xlwings Integration** - Individual trader reports generated from Excel
3. **Streamlit Dashboard** - Aggregated portfolio manager view

All P&L, volatility, and risk metrics are denominated in USD ($).

## Features

- Real-time position tracking and P&L monitoring
- Automated risk calculations (position vol, portfolio vol, marginal vol)
- 2-Sigma drawdown analysis (1-day, 1-week, 2-week, 1-month)
- SVB/CS stress scenario (March 2023) testing
- Trade scoring system (9-factor checklist)
- Potential trade analysis with risk budget checks
- Performance analytics and postmortem tracking
- Multi-trader aggregation and overlap detection

## Installation

### Prerequisites

- Python 3.8 or higher
- Microsoft Excel
- Bloomberg Terminal with API enabled (optional - only if using Bloomberg data provider)

### Setup

1. Clone the repository:
```bash
cd /path/to/portfolio_risk_system
```

2. Install Python dependencies:
```bash
pip install -r requirements.txt
```

3. Configure data provider and file paths in `python/config.py`

4. If using Bloomberg:
   - Ensure Bloomberg Terminal is running
   - Test API connection with the test script

## Configuration

Edit `python/config.py` to configure:

- **Data Provider**: Choose between "BBG" (Bloomberg) or "INHOUSE"
- **File Paths**: Set locations of trader Excel files
- **Risk Parameters**: Set default correlation, vol targets
- **Bloomberg Settings**: Configure API host/port if using Bloomberg

### Switching Data Providers

The system supports pluggable data providers via an abstract interface:

- **BBG**: Uses Bloomberg API for live prices and historical data
- **INHOUSE**: Stub for custom in-house data system (requires implementation)

To switch providers, edit `DATA_PROVIDER` in `config.py`.

To implement in-house provider, see `docs/data_provider_guide.md`.

## Usage

### For Traders

1. **Open your Excel workbook** (e.g., `excel/positions_trader1.xlsx`)
2. **Enter trades** in the Positions sheet:
   - Fill in all required fields (Ticker, Direction, BPV, Entry Level, etc.)
   - Complete the 9-factor scoring checklist
   - Mark trades as "Open", "Closed", or "Potential"
3. **Run the report**:
   - Click the "Generate Report" button in Excel, or
   - Run: `python python/xlwings_report.py --trader 1`
4. **Review your report** in the "Report" sheet

See `docs/excel_template_guide.md` for detailed instructions.

### For Portfolio Manager

1. **Launch the dashboard**:
```bash
streamlit run python/streamlit_app.py
```

2. **Navigate pages**:
   - **Book Summary**: Aggregated risk metrics, drawdowns, SVB stress
   - **All Positions**: View and filter all positions across traders
   - **Trader Drill-Down**: Deep dive into individual trader books
   - **Performance Analytics**: P&L over time, score analysis, win rates
   - **Trade History**: Complete history with filters and export
   - **Potential Trades**: Review proposed trades and risk impact

See `docs/streamlit_dashboard_guide.md` for page-by-page guide.

## Risk Calculations

### Position Volatility
```
Annual Rate Vol (bp) = Daily Vol × √252
Position Vol ($) = BPV ($k) × Annual Rate Vol (bp) × 100
```

### Portfolio Volatility
```
Portfolio Vol = √(Σσᵢ² + ρ × Σᵢ≠ⱼ(σᵢ × σⱼ))
```
Where ρ is the correlation between positions.

### 2-Sigma Drawdowns
```
1-day:   2 × (Annual Vol / √252)
1-week:  2 × (Annual Vol / √52)
2-week:  2 × (Annual Vol / √26)
1-month: 2 × (Annual Vol / √12)
```

### SVB Stress Scenario

Applies actual rate moves from March 8-15, 2023 (SVB/Credit Suisse crisis):
```
Stress P&L = BPV × SVB Move (bp) × 100 × Direction Multiplier
```
Direction Multiplier = -1 for Long, +1 for Short

See `data/svb_stress_moves.csv` for reference moves by ticker.

## Trade Scoring System

9-factor checklist (each worth 0, 0.5, or 1 point):

1. **Directional Conviction**: Macro view supports trade
2. **Valuation Support**: Model/rich-cheap analysis supports
3. **Flow Supportive**: Client flows, issuance, redemptions supportive
4. **Positioning Supportive**: Market positioning (CFTC, surveys) supportive
5. **Momentum/MR**: Momentum-aligned OR mean reversion from extreme
6. **Liquidity**: Can get in/out cleanly
7. **Entry Z-Score**: Auto-calculated from 3-month history
8. **Timing/Seasonality**: Catalyst or seasonal pattern identified
9. **Area of Expertise**: Trade in trader's wheelhouse

Total Score ranges from 0 to 9. Performance analytics show whether higher scores correlate with better outcomes.

## Troubleshooting

### Bloomberg API Issues

- Ensure Bloomberg Terminal is running and logged in
- Check API permissions in Bloomberg
- Verify `blpapi` is installed correctly
- Test connection with simple API call

### xlwings Issues

- Ensure Excel is installed
- On Windows, xlwings should work out of the box
- On Mac, may need to install xlwings add-in: `xlwings addin install`

### Streamlit Issues

- If dashboard doesn't load, check file paths in config.py
- Ensure all trader Excel files exist
- Check data provider is configured correctly
